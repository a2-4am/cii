Differences from Copy ][ Plus 8.4 to Copy ][ Reboot 1.0

- Menu items and messages are displayed in mixed case if available.

- Menu items can now be selected with single-letter hotkeys.

- Quitting to ProDOS could end up writing bad data on block 2 of the boot volume, rendering it unbootable. This has been fixed.

- Cataloging a large hard disk could cause subsequent floppy disk copies to fail until Copy ][ Plus was restarted. This has been fixed.

- Catalog displays and file lists recognize 23 more filetypes, mostly IIgs-related.

- Change Boot Program now supports Pronto-DOS in addition to Apple DOS 3.3. Sector numbers for the startup program and filetype are offset by 2.

- In the Copy File option, "Delete" has been renamed to "Unmark", and the hotkey [D] has been changed to [U]. Pressing [D] still works to unmark a file.

- In the Quit option, it now says "Press [Return] to quit to ProDOS" instead of "Press [Q]". Pressing [Q] still works.

- Copy ][ Plus v6.0 introduced a secret feature to press [M] on Quit to enter the monitor. This is now displayed.

- Directory trees and Catalog w/File Lengths will always use 80 columns if available. Other catalog options will always use 40 columns.

- Printer support has been removed.

- Bit copy support has been removed.
