COPY DISK (2 DRIVES)(64K)

Notes:

Test copying a 5.25-inch disk with 2 drives and only 64K. There is application logic to use auxmem and/or other memory cards for the copy disk operation, so this specifically tests the code path where auxmem is not available.

source.do is the ProDOS 2.4.3 master disk. It is not copy protected.

Requirements:

- two disk drives in slot 6
- 64K (no memory cards, no 80-column cards)

Steps:

- Duplicate blank-formatted-DOS33.do to target.do
- Launch Copy ][ Reboot
- Mount source.do in Slot 6, Drive 1
- Mount target.do in Slot 6, Drive 2
- Copy > Disk > select source device Slot 6, Drive 1 > select target device Slot 6, Drive 2
- Press [Return] to start copy operation and wait until it completes
- Quit Copy ][ Reboot

Expectations:

- Copy operation reads tracks $00 through $03 from source disk, then
  writes tracks $00 through $03 to target disk, then
  reads tracks $04 through $07 from source disk, then
  writes tracks $04 through $07 to target disk, then
  reads tracks $08 through $0B from source disk, then
  writes tracks $08 through $0B to target disk, then
  reads tracks $0C through $0F from source disk, then
  writes tracks $0C through $0F to target disk, then
  reads tracks $10 through $13 from source disk, then
  writes tracks $10 through $13 to target disk, then
  reads tracks $14 through $17 from source disk, then
  writes tracks $14 through $17 to target disk, then
  reads tracks $18 through $1B from source disk, then
  writes tracks $18 through $1B to target disk, then
  reads tracks $1C through $1F from source disk, then
  writes tracks $1C through $1F to target disk, then
  reads tracks $20 through $22 from source disk, then
  writes tracks $20 through $22 to target disk
- Once copy operation starts, there are no further prompts before main menu appears
