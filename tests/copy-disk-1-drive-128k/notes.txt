COPY DISK (1 DRIVE)(128K)

Notes:

Test copying a 5.25-inch disk with 1 drive and 128K. There is application logic to use auxmem and/or other memory cards for the copy disk operation, so this specifically tests the code path where auxmem is available.

source.do is the ProDOS 2.4.3 master disk. It is not copy protected.

Requirements:

- one disk drive in slot 6
- 128K

Steps:

- Duplicate blank-formatted-DOS33.do to target.do
- Launch Copy ][ Reboot
- Mount source.do in Slot 6, Drive 1
- Copy > Disk > select source device Slot 6, Drive 1 > select target device Slot 6, Drive 1
- Follow prompts to insert source disk (source.do) and target disk (tqrget.do) until copy is complete
- Quit Copy ][ Reboot

Expectations:

- During operation, first prompt is to "insert target disk" after reading track $11 from source
- Second prompt is to "insert source disk" after writing track $11 to target
- Third prompt is to "insert target disk" after reading track $22 from source
