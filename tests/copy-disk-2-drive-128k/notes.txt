COPY DISK (2 DRIVES)(128K)

Notes:

Test copying a 5.25-inch disk with 2 drives and 128K. There is application logic to use auxmem and/or other memory cards for the copy disk operation, so this specifically tests the code path auxmem is available.

source.do is the ProDOS 2.4.3 master disk. It is not copy protected.

Requirements:

- two disk drives in slot 6
- 128K

Steps:

- Duplicate blank-formatted-DOS33.do to target.do
- Launch Copy ][ Reboot
- Mount source.do in Slot 6, Drive 1
- Mount target.do in Slot 6, Drive 2
- Copy > Disk > select source device Slot 6, Drive 1 > select target device Slot 6, Drive 2
- Press [Return] to start copy operation and wait until it completes
- Quit Copy ][ Reboot

Expectations:

- Copy operation reads tracks $00 through $11 from source disk, then
  writes tracks $00 through $11 to target disk, then
  reads tracks $12 through $22 from source disk, then
  writes tracks $12 through $22 to target disk
- Once copy operation starts, there are no further prompts before main menu appears
