ALPHABETIZE CATALOG (PRODOS)

Notes:

beagle-graphics-ProDOS.po is a ProDOS disk named BEAGLE.GRAPHICS and a subdirectory named SUBDIRECTORY.

Requirements:

- two disk drives in slot 6
- no clock

Steps:

- Duplicate beagle-graphics-ProDOS.po to sorted-v84.po
- Launch Copy ][ Plus v8.4
- Mount sorted-v84.po in Slot 6, Drive 2
- Alphabetize Catalog > select Slot 6, Drive 2 > select BEAGLE.GRAPHICS > [G]o
- Alphabetize Catalog > select Slot 6, Drive 2 > select SUBDIRECTORY > [G]o
- Quit Copy ][ Plus
- Duplicate beagle-graphics-ProDOS.po to .sorted-reboot.po
- Launch Copy ][ Reboot
- Mount sorted-reboot.po in Slot 6, Drive 2
- Alphabetize Catalog > select Slot 6, Drive 2 > select BEAGLE.GRAPHICS > [G]o
- Alphabetize Catalog > select Slot 6, Drive 2 > select SUBDIRECTORY > [G]o
- Quit Copy ][ Reboot

Expectations:

$ diff beagle-graphics-ProDOS.po sorted-reboot.po
Binary files beagle-graphics-ProDOS.po and sorted-reboot.po differ

$ diff sorted-reboot.po sorted-v84.po
(no output)
